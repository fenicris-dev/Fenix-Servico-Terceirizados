    Manual rápido

    • Em Serviços, use + Novo Serviço pra cadastrar; clique no código do serviço pra ver/lançar os dias trabalhados.
    • O botão + Dia registra um dia de atendimento — isso é o que conta como "atendimento" nos relatórios (dias distintos, não o período corrido).
    • Em Clientes, clique numa linha pra ver o histórico completo, editar ou excluir o cliente.
    • A bolinha no topo mostra se você está sincronizado com o Fênix Core; se ficar amarela/vermelha, seus dados continuam salvos neste aparelho e sincronizam sozinhos quando a internet voltar.
    • Use Exportar Dados no Dashboard pra baixar um backup em JSON a qualquer momento.
